GET THE APK (no Android Studio needed)
1. Create a free account at github.com and make a new repository.
2. Upload everything in this folder (keep the .github folder).
3. Open the Actions tab > "Build APK" > wait ~5 min for the green tick.
4. Open the run, download the "AppGuard-apk" artifact, unzip, and copy app-debug.apk to your phone.
5. Install it (allow "install unknown apps"), then open App Guard.

USING THE APP
1. Create a PIN, tap "Enable the closing service", turn App Guard on in Accessibility settings.
2. Tick apps, set minutes per day, tap "Save selections".
